# Enable free GitHub Pages (easiest method)

You do **not** need the Actions tab for this method.

## Steps (in browser)

1. Log in as **SGk46**: https://github.com/login  
2. Open the repo: https://github.com/SGk46/pomodoro-focus-stats  
3. Click **Settings** (repo top menu; only you see this when logged in as owner)  
4. Left sidebar → **Pages**  
5. Under **Build and deployment**:
   - **Source:** Deploy from a branch  
   - **Branch:** `main`  
   - **Folder:** `/ (root)`  
6. Click **Save**

Wait 1–2 minutes, then open:

**https://sgk46.github.io/pomodoro-focus-stats/**

## If you don’t see Settings or Actions

- You must be logged in as **SGk46** (not a different account).  
- On mobile: menu (⋯) → Settings.  
- Actions tab is next to Code / Issues / Pull requests — only on the **repo** page, not on your profile.
